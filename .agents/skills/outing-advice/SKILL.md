# 出门建议

在用户询问「今天/明天要不要带伞」「穿什么合适」「路况/限行」「空气质量」等**外出相关**问题时启用本 Skill。

## 工具（必读）

- **只使用内置 `web_search` 工具**完成联网检索（本项目对应 Tavily 搜索封装），不要改用其它搜索工具名。
- 每个查询语句用**简短中文关键词**，可拆成多轮 `web_search`（例如先天气再空气质量）。

## 推荐流程

1. 若信息不全，先澄清：**城市（或区县）**、**出门时段**、**交通方式**（步行 / 驾车 / 公共交通）。
2. 用 `write_todos` 列出：检索项 → 汇总 → 成稿（复杂时再开待办即可）。
3. 按需调用 `web_search`，典型查询示例（按实际日期与用户地点替换）：
   - `{城市} 今日天气 气温 降水`
   - `{城市} 空气质量 AQI 今天`
   - `{城市} 限行 今天`（若用户驾车）
   - `{城市} 地铁 公交 临时调整`（若用户提到通勤）
4. 长摘录可写入虚拟文件 `/workspace/notes/出门检索摘录.md` 再压缩，避免上下文溢出。

## 回复结构（面向用户）

用简体中文、只分三条列出建议结果，只需要给出结论，不需要过程。建议包含：

- **天气与体感**：气温区间、降水概率、风力；是否需要雨具或防晒。
- **穿衣**：只需要给出需要穿什么，比如西药穿毛衣或者需要穿短袖。
- **健康与携带物**：空气质量敏感人群提示；比如如果有花粉等，需要提示带口罩等。

## 边界

- 不编造具体数值；检索失败或结果冲突时如实说明，并给出保守建议（如「备折叠伞」）。
- 不涉及医疗诊断；仅作一般性外出参考。
